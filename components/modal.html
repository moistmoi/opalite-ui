<opalite-modal>

Centered dialog with backdrop. Self-contained — include the trigger via slot="trigger".

Basic usage

Attributes & slots

NamePurpose
titleDialog heading text
openBoolean attribute; toggles visibility
slot="trigger"Element that opens the modal when clicked
slot="footer"Action buttons row
data-closeAdd to any element inside the modal to close it on click

Programmatic control

const modal = document.querySelector('opalite-modal');
modal.show();
modal.hide();
