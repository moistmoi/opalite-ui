Toast

Stacking notifications. Triggered via the global window.opalite.toast() function — a toaster is auto-mounted on the page.

Trigger via inline onclick

API

// Anywhere in your code
window.opalite.toast('Hello!');                       // success, 3.5s
window.opalite.toast('Oops', 'error');                // error variant
window.opalite.toast('Stay forever', 'success', 0);   // duration 0 = no auto-dismiss

// Or via custom event (e.g. from another script)
window.dispatchEvent(new CustomEvent('opalite:toast', {
  detail: { message: 'Hello!', type: 'success' }
}));
