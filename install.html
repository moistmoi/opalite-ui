How to
install & use.

Opalite UI is a zero-dependency web component library. No npm, no bundler, no framework. Works in any HTML file.

1

Add the CDN script tag

Paste this one line into the <head> of your HTML file. That's the entire install.

<!DOCTYPE html>
<html>
<head>
  <!-- Add this line 👇 -->
  <script src="https://cdn.jsdelivr.net/gh/moistmoi/opalite-ui@main/dist/opalite-ui.js"></script>
</head>
<body>
  <!-- Your components go here -->
</body>
</html>

The script also auto-loads opalite-ui.css — you don't need to link it separately.

2

Write components in your HTML

Use Opalite components exactly like regular HTML tags. No JavaScript needed.

<!-- Buttons -->
<opalite-button variant="primary">Click me</opalite-button>
<opalite-button variant="secondary">Cancel</opalite-button>
<opalite-button variant="danger" loading>Deleting...</opalite-button>

<!-- Badges -->
<opalite-badge variant="success">Active</opalite-badge>
<opalite-badge variant="warning">Beta</opalite-badge>

<!-- Alerts -->
<opalite-alert type="success" title="Saved" dismissible>
  Your changes have been saved.
</opalite-alert>
3

Use modal, dropdown & tabs

Interactive components are self-contained — include the trigger inside the component via slot="trigger".

<!-- Modal -->
<opalite-modal title="Confirm action">
  <opalite-button slot="trigger">Open modal</opalite-button>
  <p>Are you sure?</p>
  <div slot="footer">
    <opalite-button variant="secondary" data-close>Cancel</opalite-button>
    <opalite-button variant="primary" data-close>Confirm</opalite-button>
  </div>
</opalite-modal>

<!-- Dropdown -->
<opalite-dropdown>
  <opalite-button slot="trigger" variant="secondary">Options ▾</opalite-button>
  <a href="#">View profile</a>
  <a href="#">Settings</a>
  <hr>
  <a href="#" style="color: red;">Sign out</a>
</opalite-dropdown>

<!-- Tabs -->
<opalite-tabs>
  <opalite-tab label="Overview" active>Overview content</opalite-tab>
  <opalite-tab label="Activity">Activity content</opalite-tab>
  <opalite-tab label="Settings">Settings content</opalite-tab>
</opalite-tabs>
4

Trigger toasts from anywhere

The toast system mounts itself automatically. Call it from HTML or JavaScript.

<!-- From HTML -->
<opalite-button onclick="opalite.toast('Saved!')">Save</opalite-button>
<opalite-button onclick="opalite.toast('Error', 'error')">Error</opalite-button>

<!-- From JavaScript -->
<script>
  // Types: 'success' (default) or 'error'
  opalite.toast('Profile updated');
  opalite.toast('Something went wrong', 'error');
  opalite.toast('Pinned forever', 'success', 0); // 0 = never auto-dismiss
</script>
Try success toast Try error toast
5

Customize with CSS variables

Override design tokens globally or per-element — no file editing needed.

<style>
  /* Change every component globally */
  :root {
    --opalite-bg: #4f46e5;          /* primary button color */
    --opalite-radius: 0.75rem;       /* border radius */
    --opalite-font: 'Your Font', sans-serif;
  }
</style>

<!-- Or override one element -->
<opalite-button style="--opalite-bg: #10b981;">Green button</opalite-button>
